SDG Alignment (for the Revised Project Proposal section):
IKeriKin supports SDG 4 (Quality Education) by giving Filipino children with special
educational needs — ASD, ADHD, dyslexia, Down syndrome, speech delay, and
developmental delay — access to personalized, accessible learning content that
mainstream materials don't provide. It also touches SDG 10 (Reduced Inequalities)
by lowering the barrier for families who lack access to specialized SPED resources.

Summary of work completed:
- Rebuilt the app's Material 3 theme (colors, buttons, cards, dialogs, nav bar) for a
  consistent, accessible look across light and dark mode.
- Added a responsive navigation shell: bottom nav bar on phones, a side navigation
  rail on tablets/desktop/web.
- Polished the Home, Learn, AI Lesson Generator, AI Lesson, Progress, Settings,
  Admin, Child Profile, and Auth screens with clearer layouts, icons, and empty/
  loading/error states.
- Verified the app compiles and runs cleanly: `flutter analyze` reports no issues
  and `flutter test` passes.
- Committed and pushed all work to GitHub.

REFLECTION (100-150 words)

This week I revised the IKeriKin proposal and set up the Flutter project with a
clean, organized structure (presentation, domain, data, application, and core
folders). I implemented the five core screens — Home, Learn, AI Lesson Generator,
AI Lesson, and Progress — connected with working navigation using GoRouter, and
polished the UI with a consistent Material 3 theme, responsive layouts, and
accessibility support (large text, high contrast, reduced motion). I also created
a GitHub repository and pushed my initial commit.

The main challenge was making layouts respond correctly across very different
screen sizes, from phones to desktop web, without breaking existing screens. I
resolved this by building a shared ResponsiveGrid/ResponsiveBody widget and a
navigation shell that switches between a bottom bar and a side rail based on
screen width, then verified everything with `flutter analyze` and `flutter test`
before committing.
