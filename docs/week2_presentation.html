Project Overview

AI-powered personalized learning for SPED children

IKeriKin is a Flutter app that gives Filipino children with special educational needs — ASD, ADHD, dyslexia, Down syndrome, speech delay, and developmental delay — access to personalized, accessible learning content that mainstream materials don't provide.

SDG 4 · Quality Education SDG 10 · Reduced Inequalities Flutter · Riverpod · GoRouter Supabase (Auth, DB, Edge Functions)

Reflection

What we learned this week

We revised the IKeriKin proposal and set up the Flutter project with a clean, layered structure (presentation, domain, data, application, core). We implemented the five core screens — Home, Learn, AI Lesson Generator, AI Lesson, and Progress — connected with working navigation, and polished the UI with a consistent Material 3 theme, responsive layouts, and accessibility support.

The main challenge was making layouts respond correctly across screen sizes, from phones to desktop web. We resolved this with a shared ResponsiveGrid/ResponsiveBody widget and a navigation shell that adapts to screen width, verified with flutter analyze and flutter test before every commit.
